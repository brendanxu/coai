- UX sprint PKG-N1..N5 ✅ (admin orders UI, /orders detail, home dashboard reorient)
- PKG-CLEANUP (chat/dead routes deleted) ✅
- PKG-M1-1+2 (`auth.RedeemPlanForOrder` + LS/Hupijiao L2 dispatch) ✅

- PKG-M1-4 (`billing.StartCron` daily ExpirePlans) ✅
- W1-W5 Path 1 prompt cache + provider pricing seed ✅
- **NEW v0.22 (this branch)**: TokenPlans dual CTA + Hupijiao checkout endpoint + LS plan_code injection + token-99 plan seed

Schema migrations pending production runtime: `gtk_provider_pricing` (16 row seed), `gtk_billing_config` (markup_multiplier=1.300 seed), `gtk_user_plan.order_id` UNIQUE, gtk_app_usage_log V2 cache columns + attribution columns, `gtk_plan` token-99 row seed.

**v0.20 deploy (2026-05-10) panic-ed 3 times** on real MySQL despite SQLite tests passing. v0.22 is a larger surface — read the rollback section before starting.
